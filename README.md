# Homelab Icons

Public, authentication-free icon assets for homelab dashboards and notifications.

## Argus

ARGUS — A Raspberry-pi Guardian for Uptime & Services.

- `argus/argus.png` — default raspberry-red icon
- `argus/argus-red.png` — raspberry-red variant
- `argus/argus-gray.png` — warm-gray variant
- `argus/argus-ivory.png` — ivory variant
- `argus/argus-kuma.png` — moss-gray Uptime Kuma watchdog variant
